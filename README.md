# lineoutrugby

LINE OUT official website — helping Italian rugby players move to Spain.

**Non parti da solo. · Live, Learn & Play**

Static site (no build step): open `index.html` or serve the folder with any static server, e.g.

```sh
npx http-server .
```

## Structure

- `index.html` — single-page site (Italian)
- `css/style.css` — styles, brand palette and self-hosted `@font-face` rules
- `assets/crest.svg` — LINE OUT crest (vector, self-contained)
- `assets/fonts/` — Anton + Archivo (latin subsets, woff2)

## Brand

Per the visual identity guidelines v1.0: granata `#3F0909` and crema `#F6E4BE` as warm bases, ambra `#E0A23F` as the only accent; Anton (display, italic) + Archivo (text); no gradients, no blue.
